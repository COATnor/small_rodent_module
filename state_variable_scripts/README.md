# State variable scripts

Scripts for calculating state variables for the COAT small rodent module and creating new versions of the state variables to upload to the COAT data portal.

## Scripts

| Script | Purpose |
|---|---|
| `calculate_state_variable_lemming_abundance.R` | Used to calculate the state variable V33_rodents_norwegian_lemming_abundance_intensive. New state variable version created in same script. |
| `calculate_state_variable_mustelide_abundance.R` | Used to calculate the state variable V37_specialist_predators_mustelide_abundance_intensive. New state variable version created in same script.
| `calculate_state_variable_shrub_abundance_snowbeds.R` | Used to calculate the state variable V85_snowbed_dwarf_shrub_abundance_intensive. New state variable version created in same script. |
